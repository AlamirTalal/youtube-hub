# FakeTube — يوتيوب على مزاجك

فيد يوتيوب مخصص **للمواضيع اللي يهمك تتابعها بس**. مفيش ترندات ولا محتوى مش عايزه: إنت بتختار اهتماماتك (أو تكتب مواضيعك بنفسك)، والتطبيق يبني لك فيد من البحث في يوتيوب، ويتعلم من تفاعلك (فتح / لايك / اشتراك)، ويخفي اللي مش عاجبك.

## المميزات

- **فيد مخصص**: بيختار ٣ اهتمامات بوزن حسب نقاط تفاعلك، وبيغيّر ترتيب النتائج عشوائيًا.
- **مواضيعك الخاصة**: ضيف أي كلمة بحث بنفسك من شاشة التعديل.
- **"مش مهتم"**: زرار على كل كارت يخفي الفيديو ويقلل وزن الموضوع، مع "تراجع".
- **حظر القنوات**: من مشغل الفيديو، مع إدارة للقنوات المحظورة والمتابَعة.
- **مشغل داخلي** مع مدة الفيديو، المشاهدات، تاريخ النشر، لايك واشتراك.
- **اتفرج بعدين**: احفظ أي فيديو بزرار واحد، وارجع له من تاب "اتفرج بعدين" (لحد ٣٠٠ فيديو).
- **قوايم تشغيل**: اعمل قوايم باسمك من مشغل الفيديو أو من تاب "قوايمي"، وضيف/شيل فيديوهات، مع حذف القائمة و"تراجع".
- **استكمال الفيديو**: بيحفظ مكان التوقف كل ٥ ثواني وعند القفل، ولما تفتح الفيديو تاني بيكمل من نفس النقطة (أو "من الأول" بزرار).
- **صفحة إحصائيات**: إجمالي الفيديوهات ومدة المشاهدة، أكتر المواضيع والقنوات اللي بتتفرج عليها، ورسم لآخر ٧ أيام، مع زرار مسح وتراجع.
- **كروت نضيفة**: العنوان واسم القناة بس — من غير وصف ولا مشاهدات ولا تاريخ.
- **فريم عشوائي بدل الصورة المصغرة**: افتراضيًا الكارت بيعرض فريم من الفيديو نفسه؛ تقدر ترجّع الصور المصغرة من الإعدادات.
- **٧ تابات**: الرئيسية، اللايكات، السجل، اتفرج بعدين، قوايمي، قنواتي، إحصائياتي.
- **عربي/إنجليزي** بتبديل RTL/LTR كامل، و**دارك مود**.
- **كل حاجة محفوظة** في المتصفح: البروفايل، النقاط، اللايكات، السجل، الاشتراكات، القنوات المحظورة، اللي اتشاف، اتفرج بعدين، القوايم، أماكن التوقف، والإحصائيات.
- **كيبورد وإتاحة**: تنقل كامل بالكيبورد، ESC يقفل النوافذ، Focus trap، ARIA مترجمة.
- **منع الشورتس** (أقل من ٦٠ ثانية) وفلتر الفيديوهات غير القابلة للتضمين.
- **توفير الحصة**: كاش للطلبات، `maxResults=50`، وRate limit بسيط على الـ API.

## الهيكل

```
index.html            واجهة الصفحة الواحدة
style.css             التنسيقات (متغيرات ثيم + RTL + Responsive)
app.js                كل منطق الواجهة (فيد، بحث، تخزين محلي، إعدادات)
api/search.js         Vercel Serverless Function: وسيط آمن لـ YouTube Data API
dev/mock-server.mjs   سيرفر محلي ببيانات وهمية للتجربة بدون مفتاح
```

## تشغيل سريع (بدون مفتاح يوتيوب)

```bash
npm run dev:mock
# افتح http://localhost:4321
```

ده بيشغّل السيرفر المحلي ببيانات وهمية — مناسب لتجربة الواجهة والتعديل على التصميم.

## تشغيل حقيقي محليًا

1. اعمل مفتاح من [Google Cloud Console](https://console.cloud.google.com/) وفعّل **YouTube Data API v3**.
2. ثبّت Vercel CLI أو استخدم `npx`:

```bash
npx vercel link
npx vercel env add YOUTUBE_API_KEY    # أو من Dashboard
npx vercel dev
```

أو نزّل المتغيرات محليًا ثم شغّل:

```bash
npx vercel env pull .env.local
npx vercel dev
```

## النشر على Vercel

1. ارفع المشروع (GitHub أو `vercel`).
2. من **Project → Settings → Environment Variables** ضيف `YOUTUBE_API_KEY`.
3. Deploy. الواجهة ثابتة و`api/search.js` بيشتغل تلقائيًا كـ Serverless Function.

## حساب الحصة (Quota)

- كل طلب `search.list` = **100 وحدة**، و`videos.list` = **1 وحدة**.
- الحصة المجانية الافتراضية **10,000 وحدة/يوم** ≈ **100 عملية بحث**.
- تحميل صفحة فيد واحدة = ٣ عمليات بحث (٣ اهتمامات) ≈ ٣٠٠ وحدة.
- عشان كده في كاش ٥ دقايق على CDN وعلى المتصفح، و`maxResults=50` بياخد أكبر عدد نتايج بنفس التكلفة.
- لو محتاج استخدام أكتر: فعّل Billing، أو قلل عدد الاهتمامات في كل تحميلة، أو استخدم Cache مشترك (Vercel KV / Upstash Redis).

## الإعدادات

- **استخدام الصور المصغرة**: افتراضيًا مقفول، والكارت بيعرض فريم عشوائي من الفيديو (`hq1/hq2/hq3` من يوتيوب) بدل الصورة المصغرة. لو الفريم مش متاح بيرجع تلقائيًا للصورة المصغرة.
- **إظهار المشاهدات والتاريخ في الكروت**: افتراضيًا مقفول، والكارت فيه الصورة والعنوان واسم القناة بس.
- **مسح الإحصائيات**: بيمسح كل أرقام صفحة الإحصائيات، مع زرار "تراجع".

## استكمال الفيديو

المشغل بيستخدم YouTube IFrame API لحفظ وقت المشاهدة كل ٥ ثواني، وعند قفل المشغل، وعند قفل الصفحة. لو الـ API مش متاح أو اتأخر، بيستخدم `embed` مباشر مع `start=N` عشان يبدأ من نفس النقطة برضه. الفيديو اللي خلص بيتمسح له مكان التوقف تلقائيًا.

## التخصيص

- **اهتمامات جاهزة**: عدّل مصفوفة `INTERESTS` في `app.js` (كل اهتمام له كلمات بحث بالعربي والإنجليزي).
- **لغات إضافية**: ضيف عنصر لـ `LANGS` وكلمات بحث لكل اهتمام باللغة الجديدة.
- **الترجمة**: كل النصوص في كائن `i18n` أعلى `app.js`.

## حدود معروفة

- مفيش تسجيل دخول — البيانات محلية على الجهاز فقط (مفيش مزامنة بين الأجهزة).
- شكل الفيديو في المشغل جاي من يوتيوب نفسه (بيحتاج إنترنيت).
- الفريم العشوائي بيستخدم الفريمات اللي يوتيوب بيولّدها تلقائيًا (`hq1/hq2/hq3`)، مش استخراج فريم حقيقي من داخل المشغل (ده مش ممكن تقنيًا بسبب قيود الـ Cross-origin).
- الـ iframe API ممكن يتعطل في بيئات معينة؛ في الحالة دي بيشتغل الـ embed المباشر، والاستكمال بيعتمد على آخر مكان محفوظ قبل كده.

## أفكار قادمة

- مزامنة عبر الأجهزة (Supabase/Firebase).
- فلاتر إضافية (أقل مدة، استبعاد قنوات، كلمات مفتاحية ممنوعة).
- PWA + إشعارات فيديوهات جديدة لقنواتك.
